Defence in depth

The path of a request

Each layer stops what the previous one let through. If one gives way, the next one holds.

  1. 1 Internet A single inbound port, no other door open.
  2. 2 Firewall Forwards only to the WAF, isolates every zone.
  3. 3 WAF OWASP rules, geo-filtering, rate limiting.
  4. 4 SSO One directory, two-factor authentication.
  5. 5 Application In its own zone, with no access to the rest.

Method

Four principles, applied everywhere

Everything as code

No machine or rule created by hand. OpenTofu describes the infrastructure, Ansible configures it; a second run must change nothing.

Minimal exposure

Anything public goes through a firewall, a WAF and a sign-in portal. Administration is reachable only over VPN.

Sealed zones

Each service lives in its own zone. A compromise stays contained; every allowed flow is justified in a matrix.

Everything can be restored

Automatic snapshots, encrypted and versioned secrets, written procedures — so nothing depends on memory or on a single person.
